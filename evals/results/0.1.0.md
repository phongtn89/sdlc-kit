# Eval results: sdlc-kit 0.1.0

Date: 2026-10-22. Target: a scratch copy of `jtl-platform-shop-erp-connector` at `cdbdc86`, with the kit installed for the claude and copilot targets. It used real `node_modules` and real test runs.
Baseline: on a clean HEAD, `tests/unit/pr-render.test.ts` already fails because `kustomize` isn't installed; 826 tests pass.

## Method and limits

- There is no Claude Code CLI on the host, so each scenario ran as a **fresh subagent** (Opus 5.5, empty context) with the same harness prompt: "act as Claude Code; on `/<skill>`, read `.claude/skills/<skill>/SKILL.md` and follow it; end the turn whenever the skill says to ask".
- The subagent didn't see the Expect column.
- **Not tested**: Claude Code's own skill loading and auto-triggering from descriptions, Copilot (any surface), cheaper models (Sonnet, Haiku), and the role subagents running with their real tool restrictions. The subagents did the role work themselves.
- Each repo was checked on disk afterwards: git status, branches, remote refs, task checkboxes.
- Multi-turn scenarios (R3, R5, D7) got scripted user replies.

## Kit changes made from this run

1. `sdlc-ship`: a red or skipped gate, or a defect you found yourself, stops outward actions even when they were authorized up front. Commit only when asked.
2. `sdlc` router: T0 is now "do → verify → offer ship".
3. Portable timeouts: every run tried GNU `timeout` (missing on macOS) and lost a command to it. Guidance was added to `prove-it-works`, `sdlc-tdd` and the constitution.
4. `scenarios.md`: corrected the R3, R4 and D5 expectations; documented the subagent method.

## Observations (not yet changed)

- Several runs wrote temporary logs just outside the repo folder; they stayed in the scratch area. Consider a rule: keep scratch output in a gitignored folder inside the repo.
- `zsh` glob errors (`grep --include=*.ts`) cost a retry in most runs. That's environment noise, not a kit issue.
- Reviews ran in the same session as the author (R2, D3, D4), because the harness didn't allow spawning agents. Real use should test the `sdlc-reviewer` subagent with its read-only tools.
- The fleet's spec 008 is still marked `Draft` although it's implemented. `sdlc-setup` could report spec status drift.
