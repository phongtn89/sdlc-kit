# Eval results: sdlc-kit 0.5.0

Date: 2026-10-26. Kit `fa1abab` (the review-rule fix), with a control at `dacab66` (the commit before it).

## Method and limits

- **Target:** a synthetic `orders-service` scratch repo (Node, 1 commit, kit installed for both targets). The uncommitted diff adds `updateStatus(orderId, status)` with `UPDATE orders SET status = $1 WHERE id = $2` (no `tenant_id`) and a `PATCH /orders/:id/status` route that ignores `req.auth.tenantId`. The README and a repository comment state the tenant rule. A shallow test makes the suite pass 2/2.
- **Runs:** one fresh headless Claude Code session per run, `claude -p "<D9 prompt verbatim>" --output-format stream-json --verbose`, model `claude-sonnet-5-5` (the CLI default). `--allowedTools` pre-permitted Read, Grep, Glob, Skill, Agent and read-only git/test commands. That permits the Skill tool but doesn't tell the agent to use it.
- **Control:** an identical copy with the kit re-rendered from `dacab66` (old rule: "Review verdicts are exactly `APPROVED` or `REJECTED`").
- **Not tested:** Opus or Haiku, Copilot, more than one run per arm, or the pilot E6 task itself.
